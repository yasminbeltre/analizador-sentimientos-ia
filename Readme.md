## 📌 Descripción

Herramienta que analiza texto en español e identifica automáticamente si el sentimiento expresado es positivo, negativo o neutro, usando procesamiento de lenguaje natural.

---

## 🎯 Objetivo

Permitir a empresas o personas analizar opiniones, reseñas o comentarios de forma automática, sin necesidad de leerlos uno por uno.

## ⚙️ Funciones implementadas

- Entrada de texto por el usuario
- Clasificación automática del sentimiento
- Resultado con etiqueta: **Positivo / Negativo / Neutro**

---

## 📈 Ejemplo de uso

| Texto ingresado | Resultado |
|---|---|
| "El servicio fue excelente y muy rápido" | ✅ Sentimiento **POSITIVO** |
| "Tuve una mala experiencia con el producto" | ❌ Sentimiento **NEGATIVO** |
| "El pedido llegó en la fecha indicada" | ➖ Sentimiento **NEUTRO** |

---

## 🚀 ¿Cómo ejecutarlo?

1. Abre el archivo `.ipynb` en **Google Colab**
2. Ejecuta las celdas en orden
3. Ingresa cualquier texto en español cuando se solicite
4. El modelo clasificará el sentimiento automáticamente
